제목: IPC 국제특허분류
분류: IP 용어사전
날짜: 2026-10-28
요약: 전 세계 특허 문헌을 체계적으로 분류하는 공통 언어
--------------------

**IPC(International Patent Classification, 국제특허분류)**는 스트라스부르 협정에 따라 전 세계 특허 문헌을 기술 분야별로 통일하여 분류하는 표준 체계입니다.

특허 검색(KIPRIS 등)이나 선행기술조사를 할 때 키워드 검색의 한계를 극복하기 위해 반드시 활용해야 합니다.

---

## 1. IPC의 계층 구조

IPC 코드는 대분류(섹션)부터 세분류(메인그룹, 서브그룹)까지 계층적인 트리 구조로 설계되어 있습니다.

| 계층 레벨 | 코드 예시 | 설명 |
| :--- | :--- | :--- |
| **Section (섹션)** | `H` | 8대 기술 분야 (A ~ H) 중 하나 |
| **Class (클래스)** | `H01` | 섹션 내 세부 기술군 |
| **Subclass (서브클래스)** | `H01L` | 반도체 장치, 전기적 고체 장치 |
| **Main Group (메인그룹)** | `H01L 21/00` | 특정 제조 공정 또는 부품 |
| **Subgroup (서브그룹)** | `H01L 21/02` | 보다 정밀한 기술 단위 |

## 2. IPC 8대 섹션 구분

* **A**: 생활필수품 (농업, 식품, 의류, 의료, 오락 등)
* **B**: 처리조작; 운수 (가공, 분쇄, 성형, 인쇄, 차량, 항공 등)
* **C**: 화학; 야금 (무기화학, 유기화학, 고분자, 금속 등)
* **D**: 섬유; 지류 (천, 방적, 제지 등)
* **E**: 고정구조물 (건축, 토목, 채광 등)
* **F**: 기계공학; 조명; 가열; 무기; 폭파 (엔진, 펌프, 연소장치 등)
* **G**: 물리학 (광학, 컴퓨팅, 제어, 계측 등)
* **H**: 전기 (반도체, 회로, 통신, 배터리 등)

## 3. IPC 코드가 왜 유용한가요?

동일한 기술이라도 출원인마다 사용하는 용어가 다를 수 있습니다(예: '핸드폰', '스마트폰', '이동통신 단말기'). 
키워드만으로 검색하면 누락이 발생하지만, 해당 기술에 해당하는 IPC 코드를 조합하여 검색하면 **표현의 차이와 상관없이 동일한 기술 분야의 선행 특허를 누락 없이 발굴**할 수 있습니다.
